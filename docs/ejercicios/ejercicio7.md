# Ejercicio 7 - Palíndromo más largo

## Descripción

Dado un numero, imprimir el palíndromo mas grande posible. En caso de no ser posible, imprimir "No"

## Entrada

```txt
N
```

Una unica linea con el numero del que queremos encontrar el palíndromo más grande.

## Salida

```txt
M
```

O bien, el palíndromo más grande, o bien `No`

## Restricciones

$O(N)$

## Ejemplo

### Input

```txt
3951315
```

### Output

```txt
5319135

```

### Explicación

De todos los palíndromos posibles con estos digitos, `5319135` es el mayor.

Posibilidades:

- 1359531
- 1539351
- 3159513
- 3519153
- 5139315
- 5319135
